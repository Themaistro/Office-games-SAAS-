# Improve Word Unscramble Game

The current Word Unscramble game has a very basic UI with a standard text box and ignores the dynamic questions generated by the backend database. We will overhaul this game to make it feel premium, engaging, and fully integrated with your daily mission system.

## User Review Required
Please review the proposed UI changes below. Do you prefer the user to **type on their keyboard** (which fills in visual slots on the screen, like Wordle), or would you prefer **clickable letter tiles** on the screen that the user taps to build the word? (Typing is usually faster for PC users, but clickable tiles are great for mobile). I have proposed a hybrid typing approach with visual slots below.

## Proposed Changes

### Word Unscramble Component
#### [MODIFY] `src/components/game/types/UnscrambleGame.tsx`
- **Database Integration:** Remove the hardcoded `wordsList` and instead use the `question.correct_answer` and `question.content.scrambled` provided by the backend.
- **Premium UI (Wordle-Style Slots):** Replace the standard text input box with individual, styled letter slots. As the user types on their keyboard, the letters will pop into the empty slots one by one.
- **Glassmorphism:** Apply a premium glassmorphism card effect to the main game container.
- **Animations & Mechanical Feedback:** Add a CSS shake animation that triggers if the user submits an incorrect word.
- **Hint Integration:** Improve the hint to automatically fill in and lock the first 2-3 letters in the slots directly, rather than just showing a text popup.

## Verification Plan
1. Start the Dev Test Mode to launch the Word Unscramble game.
2. Verify that typing fills the visual slots correctly.
3. Verify that entering a wrong word shakes the input and registers a mistake.
4. Verify that pressing the global "Hint" button reveals the starting letters in the slots.
5. Verify that entering the correct word succeeds the game and proceeds to the next challenge.
